# Code of Conduct

This project welcomes people learning, using, and improving Abstract, regardless
of experience, identity, or background.

## Expected behavior

- Treat people respectfully and ask for context before assuming intent.
- Critique ideas and code with concrete examples rather than personal attacks.
- Respect privacy, boundaries, and the time contributors volunteer.
- Keep discussions focused on improving the language, tools, and documentation.

Harassment, discrimination, threats, sexualized attention, doxxing, and repeated
disruption are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to **adrienverhaert@gmail.com**. This is the
maintainer's published project contact. Include links and context when safe;
do not post other people's personal information. Reports will be handled as
privately as practical, without a guaranteed response deadline.

The maintainer may remove content, request changes, restrict participation, or
block accounts according to severity and repeated behavior. This policy applies
to project issues, pull requests, discussions, and other project-maintained
spaces. The maintainer is subject to the same standards.
