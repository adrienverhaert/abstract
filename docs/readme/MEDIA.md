# README media

- `logo.svg` is the project's existing logo, reused from the extension.
- `hero.webp` is an original generated editorial illustration in the approved
  restrained hand-drawn style. It is an illustration, not a product screenshot.
- `playground-demo.gif` and `playground.webp` show a real starter compilation
  and its visual result on https://learn-abstract.vercel.app/en/playground/.
- `learning-library.webp` is a capture of the live learning library.

The browser playground is maintained in the separate Learn Abstract repository.
It uses the Rust compiler through its browser integration. README media does
not imply that the VS Code extension is the browser interface.
